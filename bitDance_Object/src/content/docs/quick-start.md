# 快速开始

bitDance 当前先提供 **基础文档 + 演示看板 + 社区讨论区**，用于快速进入产品工作流。

## 1. 环境准备

- Node.js 20+
- npm 10+
- 推荐浏览器：Chrome / Edge 最新版

```bash
npm install
npm run dev
```

## 2. 页面导览

| 页面 | 作用 |
| --- | --- |
| 首页 | 快速了解平台定位与工作流 |
| 我的策略 | 可视化策略拼装与调试 |
| 数据看板 | 查看数据覆盖和可用性 |
| 社区 | 论坛式讨论与经验分享 |

## 3. 常见问题

### 如何开始做一个策略？

进入“我的策略”，从模板画布起步，先跑通信号生成与风险约束，再连接执行节点。

### 为什么文档是 Markdown？

Markdown 维护成本低，配合 Vue 组件可快速做版本化和结构化展示，后续可以接入搜索和多语言。

### 会员中心为什么暂时不可见？

当前优先完成核心功能体验，会员体系会在功能稳定后再补齐。
