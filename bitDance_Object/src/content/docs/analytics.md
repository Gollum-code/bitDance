# 分析工具

系统提供 5 个分析工具，全部位于 `/analytics/*`，都复用同一个 vn.py 回测引擎与免费行情源。

## 1. 多策略对比（`/analytics/compare`）

同一标的、同一区间**并行回测多个策略**，把各策略的累计收益曲线归一化后叠加展示，并排比较指标。

- 怎么用：勾选最多 8 个策略，填标的与区间 → 运行
- 图表：多策略收益曲线叠加
- 表格：总收益 / 年化 / 最大回撤 / 夏普 / 胜率 / 成交笔数 并排

## 2. 因子选股器（`/analytics/screen`）

基于免费全市场行情，对样本股票做**横截面多因子打分**，输出 Top N 排行。

参与打分的 8 个因子与权重：

| 因子 | 方向 | 权重 |
| --- | --- | --- |
| 动量（区间涨幅） | 越高越好 | 25% |
| 中期趋势（相对 60 日均线） | 越高越好 | 20% |
| 波动率（年化） | 越低越好 | 15% |
| 距 60 日高点回撤 | 越低越好 | 10% |
| 量能放大（5 日均量/20 日均量） | 越高越好 | 10% |
| 均线交叉（MA20 vs MA60） | 越高越好 | 10% |
| 流动性/冲击（Amihud） | 越低越好 | 10% |

- 结果行可点击跳转到个股日线页
- **「批量同步到本地库」**：把 Top N 一次性写入 vn.py 数据库，随后可去策略页回测
- 免费源不可用时自动降级读取本地库已有数据

## 3. 参数网格优化（`/analytics/grid`）

对**单个策略参数**（`fast_window` / `slow_window` / `atr_window` / `atr_mult` / `fixed_size` 等）做多组取值扫描，展示每组的总收益、回撤与夏普。

- 输入逗号分隔的取值列表，如 `5,10,15,20,25`
- 结果有 30 分钟缓存（相同请求直接返回）

## 4. 组合回测（`/analytics/portfolio`）

单个策略在**多个标的上**分别输出信号，按权重合成**组合净值**。

- 支持 2~10 个标的，可自定义权重或一键等权重置
- 输出：组合净值曲线、总收益/年化/最大回撤/夏普、每个标的单跑收益与成交
- 实现：每个标的使用 `_run_backtest` 并行走单策略回测，把收益序列按日对齐后加权合成

## 5. 实时行情推送（`/analytics/realtime`）

WebSocket 服务端每 **3 秒**推送一次腾讯实时快照（代码/名称/现价/涨跌/买卖盘/量）。

- 支持 `sh` / `sz` / `bj` 前缀，最多 60 只自选
- 断线自动重连；WS 不可用时降级为 REST 轮询
- 行情为腾讯公开延迟行情，仅供研究演示

## 通用提示

- 回测类工具依赖本地 vn.py 数据库（需先「同步日线到本地库」）
- 因子选股与实时行情走免费腾讯接口，高频调用可能触发限流（代码已做串行 + 重试 + 本地库兜底）
